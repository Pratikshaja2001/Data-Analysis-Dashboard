# Title - Airbnb Listing & Reviews Analysis

 ## Aim – 
  To Analysis the Data of Airbnb Listing and creating interactive visualization 

## Objective – 
•	To Analysis the datasheet and find the sum of calculating host listing count 
•	To Analysis and visualizing reviews and pricing of airbnb listing
•	Creating interactive visualization for user exploration 

## Dataset  Used -
-  <a href = "https://github.com/Pratikshaja2001/Data-Analysis-Dashboard/blob/main/Airbnb_data.xlsx"> Dataset</a>

## Attributes:- 

1.	Host listing – Calculating host listing count 
2.	Id – Airbnb unique identifier for the listing
3.	Neighbourhood_group - The neighbourhood group as geocoded using the latitude and longitude against neighborhoods as defined by open or public digital shapefiles
4.	Neighbourhood - The neighbourhood as geocoded using the latitude and longitude against neighborhoods as defined by open or public digital shapefiles.
5.	Price - daily price in local currency.
6.	Minimum nights - minimum number of night stay for the listing
7.	Review – The number of reviews the listing
8.	Service fee – Service fee for hosting
9.	Room Type – Which Type of room is use for Airbnb listings

## Process –
1. Verify data for any missing values and anomalies, and sort out the same.
2. Made sure data is consistent and clean with respect to data type, data formate and values used.
3. Merge all pivot tables into one dashboard and apply slicer to make dynamic.
